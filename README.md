## Run AI models to do object detection with Scailx camera video stream.

***

#### 1. Follow Scailx document online section 3.4 for main steps to run python programs on camera to do live stream object detection.

#### https://videology-inc.atlassian.net/wiki/spaces/SUD/pages/63275010/Running+AI+models+in+Python+with+Tensorflow-lite

#### This step is very important to use git lfs to clone the repo to get large tflite model files !

#### On camera, please use git link to clone the main branch from the repository instead of https after git lfs install.

#### git clone git@github.com:VideologyInc/python-tflite-mobilenet-demo.git

#### 2. Make sure to stop go2rtc service before running any python programs to avoid conflict and restart go2rtc service after python programs finished.

#### List services using port 8554:  `lsof -i :8554`
	
#### Stop go2rtc service:  		`systemctl stop go2rtc.service`

#### Run python program to do object detection (see below) ...

#### Restart go2rtc service to make camera stream accessible again on Windows web or VLC player afterwards.
#### 	`systemctl restart go2rtc.service`

#### 3. The 2 python programs have different pros and cons. Please test running both of them with various camera settings.

#### On camera, run

#### `python3 object-detection.py -d /dev/video0`

#### Or.
#### `python3 yolo_object_detection.py -d /dev/video0	`

#### 4. To see object detction effective on Windows, please run

	`gst-launch-1.0 rtspsrc location=rtsp://scailx-ai.local:8554/stream latency=0 connection-speed=3000 ! queue ! decodebin ! queue ! videoconvert ! autovideosink sync=false`

=================================================================

#### 5. Alternatively, on Windows and Linux host (such as in VirtualBox guest systems), we can run the OpenCV python program ~/host/opencv_stream.py to access camera object detection stream to avoid complex gstreamer command in step 4.

#### 5.1	On Windows python >=3.10 venv.

#### `python opencv_stream.py`    

#### 5.2	On VirtualBox Ubuntu guest system with python >=3.10 venv.

####	Because our laptop have 2 network routes - one to company's network (10.* ip address) and one to engineering lap (ip address 192.168.*), while Scailx camera is connected to engineering network (ip address 192.168.*), in VirtualBox we need to replace the rtsp line in the python program hostname with ip address of our Scailx camera, for example
	
####    scailx_rtsp_url = "rtsp://192.168.9.31:8554/stream"

####	Now run the same command in Ubuntu python venv. 

#### `python opencv_stream.py`    

#### Enjoy object detection :-)

#### 2026.0108. Updates with new python programs to create gst rtsp server from Scailx camera with settings from pipeline json file (same syntax as Scailx Portal ;-).
#### The video stream can be viewed on Windows using VLC player as before, or by running python program from the ~/host folder using the SAME pipeline files.

#### Pipeline json files are under similar folder structure as Scailx Portal: ~/data/settings/.

#### Please refer to Azure AB#1879 for test screen images.

#### 6. On Scailx terminal, run

`python3 gst_rtsp_stream.py -h`    (Show help.)

`python3 gst_rtsp_stream.py -p data/settings/camera0_pipeline.json`    (Load camera settings and server net url from a pipeline file.)

`python3 gst_rtsp_stream.py -p data/settings/camera0_pipeline.json -t 3001`    (Load camera settings and specify port number to override pipeline file.)

`python3 gst_rtsp_stream.py -p data/settings/camera0_pipeline.json -t 0`    (Load camera settings and use random assigned port number available.)

`python3 gst_rtsp_stream.py -p data/settings/camera0_pipeline.json -t 3001 -o data/settings/camera0_port3001_pipeline.json`    
	(Load camera settings, specify port number and save updated dictionary to a new pipeline file, which can be used by host program. See below.)

#### 6. On Windows host side, assume we are in python 3.10 venv, run

`cd host`
`python opencv_stream.py -h`     (Show help.)

`python opencv_stream.py --p ../data/settings/camera0_pipeline.json`     (Load same pipeline file to access server url.)

`python opencv_stream.py --p ../data/settings/camera0_pipeline.json -t 3001`     (Load same pipeline file to access server url with port updated.)

`python opencv_stream.py --p ../data/settings/camera0_port3001_pipeline.json`     (Load the pipeline file generated by Scailx program above to access live server url.)

##### Remember that in order to use newly saved pipeline files from Scailx device, we need to scp them to Windows. For example

#### Run from parent folder of Windows local repository folder.

`echo Copy pipeline files from scailx camera to Windows.`

`scp root@scailx-ai-2.local:/root/python-tflite-mobilenet-demo/data/settings/*.json python-tflite-mobilenet-demo/data/settings/`
